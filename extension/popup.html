How to start ChunkFlow downloads
Best trigger: Right-click a file link on a webpage and choose Download with ChunkFlow.
Normal click: Auto-intercepts common file extensions (now includes .dat). If not intercepted, use the URL box below.
Badges: ⚡ Chunked = parallel chunks, ⬇ Normal (CF) = ChunkFlow used native path, 🌐 Browser = started outside ChunkFlow, ⚠ Fallback = chunking failed then native path.
